# ShadowsOfUI-XP

A **minimal, full-width XP bar** pinned to the very bottom of the screen, replacing
Blizzard's status tracking bar while you level.

- Thin bar spanning the whole screen width, with 10% notch marks.
- Rested XP shown as a blue overlay.
- Percentage labels fade in when you mouse over the bar and fade back out.
- Hidden entirely at max level (and Blizzard's bar stays hidden with it).

No settings, no commands, no saved data — install it and level.

## Changelog

A **Changelog** button in this addon's settings (Options → AddOns → Shadows of UI → XP Bar) opens its release history in a scrollable, copyable window.

## Requirements

**LibNAddOn** and **LibNUI**.
