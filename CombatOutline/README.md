# CombatOutline

Turns on WoW's **outline rendering mode** (the `OutlineEngineMode` CVar) when you enter
combat and restores your previous setting when you leave. You get crisp character
outlines when visibility matters, and the standard look the rest of the time.

Fully automatic — no settings, no commands.

## WoW: Forever

Loads on **WoW: Forever** (Interface 16001) as well as Retail.

## Dependencies

- **LibNAddOn**
