# Warbandeer: Alias

**Let your guild always know who they're talking to.** If you play a lot of alts, set an **alias** once and every guild-chat message you send is prefixed with it — e.g. `(Naz) hi all` — whenever your current character's name doesn't already give you away.

- Only **guild chat** is touched — whispers, party, raid, and public channels are never modified.
- Messages starting with `/`, `!`, `#`, `@`, or `?` are left alone.
- An optional **Starts With** rule skips the prefix when your character's name already starts with the alias (e.g. alias `Naz` on `Nazuraki`).

## Dependencies

- **LibNAddOn**, **LibNUI** — install automatically.
