# LibNUI ModelViewer

**A shared library component, not a standalone addon.** This is an optional companion to [LibNUI](https://github.com/nazumods/wow/tree/main/LibNUI) — you don't install it by hand; the addons that show a 3D character or transmog viewer declare it as a dependency and your addon manager pulls it in automatically.

It adds a `ModelScene`-backed 3D model-viewer widget (`ui.Model`) to LibNUI: left-drag to spin, right-drag to pan, mouse-wheel to zoom, all with smooth inertia. It can skin the model from a unit or an arbitrary race, try on transmog appearances and enchant illusions, and normalise wildly different race sizes to a common scale — the engine behind the suite's transmog dressing rooms.
