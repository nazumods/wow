# HideStanceBar

Hides the stance bar — per class. If you never click your stances/forms/presences but
don't want them gone on *every* character, this gives you one checkbox per
stance-using class (Warrior, Paladin, Druid, etc.), applied live.

## Settings

Found in the Blizzard settings panel under **Shadows of UI → Hide Stance Bar**: one
**show/hide toggle per class** that has a stance bar. Toggles take effect immediately,
no reload needed.

Settings are account-wide and keyed by class, so hiding the bar for Druids hides it on
all your Druids.

## Requirements

**LibNAddOn** and **LibNUI**.

## Saved data

`HideStanceBarDB` (account-wide): the per-class toggles.
