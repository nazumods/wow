# LibNUI

**A shared UI library, not a standalone addon.** LibNUI is the widget toolkit the suite's interfaces are built with — you don't install it by hand; the addons that need it declare it as a dependency and your addon manager installs it for you.

It wraps Blizzard's frames in a clean, object-oriented set of UI classes — windows, tables, tabs, buttons, dropdowns, scroll frames, accordions, stat tiles, themes, and more — with pixel-perfect "hairline" borders that stay crisp at any UI scale, and a theming system that keeps every window in the suite looking consistent.
