# BarNonce

A tiny visual tweak for the main action bars: dims the buttons of **Action Bar 1**
and **Action Bar 2** (bottom left) to 70% opacity, so they sit quieter on screen.

No settings, no commands, no saved data, no dependencies. If a future WoW patch
changes the bar internals, the addon safely does nothing.

## Dependencies

None — BarNonce uses only the base WoW API (no LibNAddOn, no LibNUI).
